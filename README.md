# gourd
### Сервис, который делает из ИИ ответа человекоподобный документ и форматирует его

>[!WARNING]
>Проект находится в процессе разработки

---

## Поддерживаемые документы
- Обычный текст
- Markdown
- Docx

---

## Доступные правила
### Рекомендованное
- Заменить тире: `Заменяет — на –`
- Заменить умножение: `Заменяет × на *`
- Заменить кавычки: `Заменяет «» на ""`
### Другое
- Заменить стрелки: `Заменяет ← → на <- ->`
### Особое
- Убрать точку с запятой: `Убирает точку с запятой в конце предложений`
