# gourd
### Сервис, который делает из ИИ ответа человекоподобный документ и форматирует его

>[!WARNING]
>Проект находится в процессе разработки

---

## Поддерживаемые документы
- Обычный текст
- Markdown
- Docx

---

## Доступные правила
### Рекомендации
**Безопасные правила, которые рекомендуется включить**
|Правило|Эффект|
|:-|-:|
|Заменить все тире|Заменяет все тире на знак минуса|
|Заменить длинное тире|Заменяет — на –|
|Заменить умножение|Заменяет × на \*|
|Заменить кавычки|Заменяет «» на ""|
### Другое
**Правила, которые могут быть вам полезны**
|Правило|Эффект|
|:-|-:|
|Заменить стрелки|Заменяет ← → на <\- \-\>|
|Заменить тангенс|Заменяет tan на tg|
### Особое
**Правила, которые сильно влияют на текст**
|Правило|Эффект|
|:-|-:|
|Убрать точку с запятой|Убирает точку с запятой в конце предложений|
